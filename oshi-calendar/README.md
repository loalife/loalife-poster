# 推し活カレンダー

推しの予定・カウントダウン・推し活費をまとめて管理する Web アプリ（PWA）です。
LOALIFE 本体とは独立していて、ビルド不要の静的ファイルだけで動きます。

## 機能

- **推しの登録とテーマカラー**：推しごとに写真（正方形に自動で切り抜き）とカラーを設定。UI は白・オフホワイト・黒・グレーが基本で、推しカラーは小さな点と「メインの推し」のアクセント（選択中のタブなど）だけに使います。黄色や白など淡い色でも、文字に使うときはコントラストを自動で確保します
- **予定管理**：ライブ・発売日・配信・誕生日・記念日・当落発表・発券などを種類別に登録（誕生日・記念日は毎年くり返し）
- **NEXT EVENT / UPCOMING**：ホームの最上部に次の予定を日付・時間・タイトルで大きく表示し、その下に今後の予定を時系列のリストで表示
- **推し活費の記録**：月ごとの合計、推し別・カテゴリ別の内訳、年間合計
- **背景写真**：好きな写真を全面の背景に設定。写真には半透明のオーバーレイ（上下は少し濃いめ）をかけ、内容はすりガラスのパネルに載せるので、派手な写真でも文字が読めます。オーバーレイ・ぼかし・写真の位置を調整できます
- ダークモード対応、オフライン対応（Service Worker）、ホーム画面に追加可能
- JSON でバックアップの書き出し／読み込み

## データの保存先

- 推し・予定・出費・設定：`localStorage`（キー `oshical.v1`）
- 背景写真：IndexedDB（長辺 2000px の JPEG に縮小して保存）
- 推しの写真：IndexedDB（キー `oshi:<推しのID>`、480px 四方の JPEG）

どちらもその端末のブラウザ内だけに保存され、サーバーには送信されません。

## ローカルで動かす

```sh
cd oshi-calendar
python3 -m http.server 8765
# → http://localhost:8765/
```

Vercel にデプロイされている場合は `/oshi-calendar/` で開けます。

## アイコンの再生成

`icon.svg` を変更したら、Playwright を使って PNG を書き出します。

```sh
NODE_PATH=$(npm root -g) node render-icons.js
```
