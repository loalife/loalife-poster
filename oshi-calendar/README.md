# 推し活カレンダー

推しの予定・カウントダウン・推し活費をまとめて管理する Web アプリ（PWA）です。
LOALIFE 本体とは独立していて、ビルド不要の静的ファイルだけで動きます。

## 機能

- **推しの登録とテーマカラー**：推しごとに写真（正方形に自動で切り抜き）・カラー・誕生日・記念日を設定。UI は白・オフホワイト・黒・グレーが基本で、推しカラーは小さな点と「メインの推し」のアクセントだけに使います
- **ホーム**：NEXT EVENT（次の予定）→ REMINDER（抽選・入金・発券の締切）→ ANNIVERSARY（誕生日・記念日まで「あと◯日」）→ UPCOMING → 今月の推し活費
- **リマインダー**：予定の種類で「チケット抽選」「入金」「発券」を選ぶと、黒いバッジと完了チェックつきで表示。期限を過ぎて未完了のものは「期限切れ」
- **カレンダー**：月表示（予定は推しカラーの点、リマインダーは黒いひし形）＋選んだ日の予定＋その月の誕生日・記念日
- **推し活費**：月合計・先月・年間累計、年間予算（今年の予算・年間累計・残り予算）、推し別・カテゴリ別の内訳、履歴
- **ノート**：写真つきの推し活レポート（日記。終わった予定に紐づけ可）と、行きたい場所リスト（カフェ・ドッグラン・イベント会場など。行った／行きたいで管理）
- **背景写真**：好きな写真を全面の背景に設定。オーバーレイ・ぼかし・写真の位置を調整できます
- ダークモード、オフライン対応（Service Worker）、ホーム画面に追加可能、JSON でバックアップの書き出し／読み込み

## ファイル構成

ビルドは不要です。`index.html` が CSS と JS を順番に読み込みます（JS はモジュールではなく通常の `<script>` で、上から順に定義を共有します）。

```
oshi-calendar/
├── index.html            画面の骨組み（ダイアログ・タブバーの置き場所）
├── css/app.css           デザイントークンと全画面のスタイル
├── js/
│   ├── core.js           定数・日付ユーティリティ・データ保存と移行・予定の展開・写真の保存
│   ├── components.js     共通部品（ヘッダー・予定の行・シート・確認ダイアログ・写真の選択・トースト）
│   ├── views/
│   │   ├── home.js       ホーム
│   │   ├── calendar.js   カレンダー
│   │   ├── money.js      推し活費（年間予算を含む）
│   │   ├── notes.js      ノート（レポート・行きたい場所）
│   │   └── settings.js   推し・設定
│   ├── forms.js          入力フォーム（予定・推し活費・推し・予算・レポート・行きたい場所）
│   └── app.js            描画・背景写真・バックアップ・操作の受け付け・起動
├── sw.js                 オフライン用のキャッシュ（ファイルを追加したら ASSETS にも追加）
└── manifest.json, icon*  PWA 用
```

## データの保存先

- 推し・予定・出費・設定：`localStorage`（キー `oshical.v1`）
- 背景写真：IndexedDB（長辺 2000px の JPEG に縮小して保存）
- 推しの写真：IndexedDB（キー `oshi:<推しのID>`、480px 四方の JPEG）
- レポート・行きたい場所の写真：IndexedDB（キー `ph:<写真ID>`、長辺 1600px の JPEG）

どちらもその端末のブラウザ内だけに保存され、サーバーには送信されません。

## ローカルで動かす

```sh
cd oshi-calendar
python3 -m http.server 8765
# → http://localhost:8765/
```

Vercel にデプロイされている場合は `/oshi-calendar/` で開けます。

## アイコンの再生成

`icon.svg` を変更したら、Playwright を使って PNG を書き出します。

```sh
NODE_PATH=$(npm root -g) node render-icons.js
```
