# 推し活カレンダー

推しの予定・カウントダウン・推し活費をまとめて管理する Web アプリ（PWA）です。
LOALIFE 本体とは独立していて、ビルド不要の静的ファイルだけで動きます。

## 機能

- **推しの登録とテーマカラー**：推しごとに写真・カラー・誕生日・記念日を設定。UI は白・オフホワイト・黒・グレーが基本で、推しカラーはアクセントだけに使います
- **ホーム**：（当日なら HAPPY BIRTHDAY）→（締切が今日・明日なら DEADLINE）→ NEXT EVENT → REMINDER → ANNIVERSARY → UPCOMING → 今月の推し活費。推しが2人以上なら、推しアイコンで絞り込めます
- **通知**：予定や締切を iPhone などのカレンダーに追加（.ics）。前日と当日の朝、時間を入れたものはその3時間前にも通知。1件ずつでも、設定画面からまとめてでも追加できます
- **チケットの申し込み**：公演ごとに FC先行・一般などの受付をいくつでも登録。状態（申込前・申込中・当選・落選・入金済み）に合わせて、申込締切（黄）・当落発表（黒）・入金期限（赤）のうち必要なものだけがホーム・カレンダー・通知に出る。チェックで次の状態へ進み、入金済みにすると金額を推し活費に記録
- **リマインダー**：「チケット抽選」「入金」「発券」は色つきのバッジと完了チェックつき。期限切れも表示
- **カレンダー**：予定（推しカラーの点）・リマインダー（ひし形）・推し活費とレポートのある日（白抜きの丸）。月のまとめと、選んだ日の予定・推し活費・レポート
- **予定の詳細**：地図・経路、周辺のホテル探し、予約したホテルの記録、現場ツール（座席メモ・持ち物チェックリスト・画面いっぱいのペンライト）、レポートへの入口
- **推し活費**：月合計・先月・年間累計、月の予算と年間の予算、推し活貯金（目標・期限・毎月の目安・貯金／引き出しの記録）、推し別・カテゴリ別の内訳、履歴
- **ノート**：写真つきの推し活レポート（座席・一緒に行った人・セトリ・かかった費用の自動集計、アルバム表示）、行きたい場所リスト、年表（終わったイベント・レポート・行った場所を年ごとに）
- **背景写真**：好きな写真を全面の背景に設定。オーバーレイ・ぼかし・写真の位置を調整できます
- ダークモード、オフライン対応（Service Worker）、ホーム画面に追加可能、JSON でバックアップの書き出し／読み込み

## ファイル構成

ビルドは不要です。`index.html` が CSS と JS を順番に読み込みます（JS はモジュールではなく通常の `<script>` で、上から順に定義を共有します）。

```
oshi-calendar/
├── index.html            画面の骨組み（ダイアログ・タブバーの置き場所）
├── css/app.css           デザイントークンと全画面のスタイル
├── js/
│   ├── core.js           定数・日付ユーティリティ・データ保存と移行・予定の展開・写真の保存
│   ├── components.js     共通部品（ヘッダー・予定の行・シート・確認ダイアログ・写真の選択・トースト）
│   ├── views/
│   │   ├── home.js       ホーム
│   │   ├── calendar.js   カレンダー
│   │   ├── money.js      推し活費（年間予算・推し活貯金を含む）
│   │   ├── notes.js      ノート（レポート・行きたい場所・年表）
│   │   ├── event.js      予定の詳細（通知・会場とホテル・現場ツール）
│   │   └── settings.js   推し・設定
│   ├── forms.js          入力フォーム（予定・推し活費・推し・予算・レポート・行きたい場所）
│   └── app.js            描画・背景写真・バックアップ・操作の受け付け・起動
├── sw.js                 オフライン用のキャッシュ（ファイルを追加したら ASSETS にも追加。ファイルを変更したら VERSION と index.html の ?v= をそろえて上げる）
└── manifest.json, icon*  PWA 用
```

## データの保存先

- 推し・予定・出費・設定：`localStorage`（キー `oshical.v1`）
- 背景写真：IndexedDB（長辺 2000px の JPEG に縮小して保存）
- 推しの写真：IndexedDB（キー `oshi:<推しのID>`、480px 四方の JPEG）
- レポート・行きたい場所の写真：IndexedDB（キー `ph:<写真ID>`、長辺 1600px の JPEG）

どちらもその端末のブラウザ内だけに保存され、サーバーには送信されません。

## ローカルで動かす

```sh
cd oshi-calendar
python3 -m http.server 8765
# → http://localhost:8765/
```

Vercel にデプロイされている場合は `/oshi-calendar/` で開けます。

## アイコンの再生成

`icon.svg` を変更したら、Playwright を使って PNG を書き出します。

```sh
NODE_PATH=$(npm root -g) node render-icons.js
```
